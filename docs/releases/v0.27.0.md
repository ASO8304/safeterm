# SafeTerm v0.27.0

Validate comma-separated typed lists in application configuration, including
IPv4 lists such as `PATIP = 192.168.222.10,10.20.30.40`.

## Typed configuration lists

Define a field inside a resource's logical context:

```json
{
  "name": "pat-ips",
  "section": "Sultan",
  "key": "PATIP",
  "type": "list",
  "item_type": "ipv4",
  "separator": ",",
  "required": true,
  "allow_empty": true,
  "min_items": 1,
  "max_items": 100
}
```

Use the real INI section name. Item count bounds are optional; `allow_empty`
permits an entirely empty value independently of key presence. Each nonempty
item must match its declared scalar type. Leading/trailing commas, empty items
and surrounding item whitespace are rejected. Errors identify the failing item
position. No regex type macros are needed or introduced.

Supported item types: string, integer, port, boolean, ipv4, ipv6, ip, cidr and
ip_port. The application value remains a string in both INI and JSON. Order,
spelling, duplicates, INI comments and unrelated bytes are preserved.
Draft validation, Manager preview/apply and the restricted writer use the same
schema. Nested lists, enum items and path items are unsupported.

The always-inactive `resources.d/TEMPLATE.json` and installed README.md/README.txt
include examples. See ADR-043 and REQ-038 for the design and requirements.

## Installation cleanup

Fresh installations no longer create `/etc/safeterm-managed` or advertise it as
the location for application files. New installation rollback snapshots no
longer include that legacy demo root. Existing directories and registered files
are left intact. Historical installation rollback manifests remain supported.
Application files continue to use the explicit paths in resource definitions.

## Install or update

Extract the matching release package, then run `sudo ./install.sh` for a fresh
installation. To update an existing installation, from the Linux administrator
shell:

```sh
sudo termctl update /path/to/safeterm-offline-amd64
sudo termctl check
```

Use the arm64 package on arm64 hosts. Finish or roll back a pending network
trial before updating. Existing administrator definitions and managed files are
preserved. Add new list schemas after updating, run `sudo termctl check` and
`sudo termctl apply`, then reconnect to SafeTerm. Older binaries do not understand
the new list schema.

## Validation

Tests cover item validation, count constraints, invalid schemas, draft feedback,
Manager preview/apply, resource compilation and INI preservation. The release
pipeline gates publication on full verification, deployment/SSH tests and real
systemd/Netplan tests. The Console PTY test rejects an invalid IPv4 list, uses Tab
to set a valid list through the real writer and verifies the resulting INI bytes.
Fresh installation also asserts the absence of `/etc/safeterm-managed`.
