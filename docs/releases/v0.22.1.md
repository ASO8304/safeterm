# SafeTerm v0.22.1

Fix Gateway startup on a fresh resources.d installation with no configuration
resources, or when one of the application/database/network profiles is unused.
Previously an unused Config Manager profile aborted Gateway startup, leaving
`/run/safeterm-gateway/gateway.sock` absent while Console login still worked.

Known profiles with no registered activation operations now receive an empty
allowlist; every activation request from them remains denied. Unknown profiles,
invalid operations and cross-profile activation remain rejected.

For an existing v0.22.0 resources.d installation, download and extract this
release, then run `sudo termctl update /path/to/safeterm-offline-amd64` (or arm64)
from an ordinary Linux administrator shell. Reconnect Console afterward.

The breaking legacy-layout restriction introduced in v0.22.0 still applies.
No dummy resource definition, permission change or additional sudo grant is needed.
