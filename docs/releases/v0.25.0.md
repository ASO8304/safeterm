# SafeTerm v0.25.0

Manage Ubuntu Server 24.04 Netplan networking through a typed, restricted CLI,
with a timed trial and recovery before committing persistent configuration.

## Network configuration

- Discover effective Netplan filenames and merge order automatically. No fixed
  `00-installer-config.yaml` or `50-cloud-init.yaml` filename is required.
- Edit existing networkd Ethernet interfaces: DHCP4, multiple static IPs, DNS,
  search domains and MTU. Define named basic routes and default gateways.
- Save a private candidate with `end`; start a trial with `execute network apply`
  and confirm as the same identity with `execute network confirm`.
- Recover on trial timeout, rejection or manager restart, with explicit rollback
  of the last confirmed change. Preserve unrelated source bytes, comments,
  ownership, permissions and extended attributes/ACLs.
- Use a separate privileged manager with authenticated Unix IPC, typed validation,
  audit events and lifecycle locking. SSH/Console brokers stay unprivileged.
- `netops` has network read/edit privileges by default. Administrators must still
  allowlist exact interfaces in `/etc/safeterm/network.json`; a fresh policy
  allows no interface edits. Additional network-only roles are available.

See `/etc/safeterm/NETWORK.md` or `/etc/safeterm/NETWORK.txt` after installation,
or [the network guide](../network-configuration.md) in the repository. This
version does not create bridges/bonds/VLANs, edit Wi-Fi/NetworkManager or manage
advanced routing. Cloud-init-generated files require an explicit administrator
acknowledgement before edits.

## Service aliases and ordered groups

Resource service definitions can hide real unit names behind administrator-defined
CLI names. Ordered groups start forwards and stop backwards; a group restart
stops all members before starting them again. Exact unit/action grants, locking
and compatible per-step audit records are retained.

## CLI changes

System diagnostics are grouped as:

```text
execute system_info host
execute system_info memory
execute system_info disk
```

These replace the root-level `execute system`, `execute memory` and
`execute disk` commands. Signed operation IDs and their authorization remain
unchanged. Tab completion and contextual `?` help follow the new command tree.

## Install or update

Download and extract the package for your architecture. From its extracted
directory, run:

```sh
sudo ./install.sh
```

For an existing installation, from the normal Linux administrator shell:

```sh
sudo termctl update /path/to/safeterm-offline-amd64
```

Use the arm64 package on arm64 hosts. Existing administrator definitions,
identities and application configuration are preserved. Installation does not
apply Netplan changes. Finish or roll back a pending network trial before
updating. Read the network guide before changing a remote management interface.
