# SafeTerm v0.32.0

Simplify terminal navigation and route configuration across SSH and Console.

## Quiet navigation

- `exit` replaces `back`. Inside configuration it moves up one level, discarding
  edits to the item being left. It closes the session only at the root prompt.
  Ctrl+] remains the immediate session exit from every level.
- `whoami` is available only at root and is absent from context help/completion.
- Login prints the main menu once. Context entry, item selection, exit, next,
  save and cancel no longer print automatic help menus. Explicit `?` and
  `COMMAND ?` retain read-only help and input-prefix preservation.
- Menu Tab completion lists child names only. Editor lists offer items; empty
  Tab inside an item stays quiet. `set` Tab still completes field names.
- Relative paths such as `edit network interface` work from the config menu.

## Clearer routes

`config network route` followed by `show` lists short route IDs with destination,
gateway, interface and metric. Select with `edit 1` or type `1` directly. Generated
hash IDs no longer clutter the display; a selected route has labeled details.
IDs are stable within the editor and map to the original backend identities.

Use `add office` to create a named route draft, then set its interface,
destination and optional gateway/metric. Unknown `edit` targets are rejected.
Existing stored names remain accepted. Delete/add does not reassign existing
selectors. Read-only restrictions and save/apply authorization remain enforced.

`next` keeps drafts; `exit` discards edits to the item; `save` validates and saves
the candidate. Network activation still requires the separate timed
`execute network apply` and confirmation flow.

Update admin training and scripts that used `back`, session-closing `exit` inside
an editor, or `edit NAME` to create routes. Packages retain the existing
administrator layout and color theme. No installer applies network settings.

Coverage includes silent navigation, one-level exit, root-only identity, help
without mutation, relevant completion, stable selectors, original backend names,
read-only enforcement, and real Console menu completion and dirty section exit.
