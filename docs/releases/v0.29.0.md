# SafeTerm v0.29.0

Make the restricted terminal easier to discover and navigate in SSH and Console.

## Command help that keeps your input

SafeTerm displays the main command menu immediately after successful login.
Type `execute ?` and press Enter to see authorized commands; the prompt retains
`execute ` so you can continue without typing it again. This also works for
configuration, item and field help, including repeated help queries.

Help remains read-only and is excluded from command history. Password and
confirmation prompts retain their existing behavior. Use Ctrl+U to clear the
current line when you want to start a different command.

## Back navigation without saving

`config` now opens a configuration menu with visible choices. Type a choice's
name or `edit NAME`; direct `config PATH` commands remain supported. Menus and
editors include Tab completion and contextual help.

Use `back` to discard unsaved edits to the item you are leaving and display its
parent menu. For example, from `network/interface/ip0`, `back` discards `ip0`'s
unsaved changes and shows the interface list. Other staged interfaces are kept.
Another `back` discards the remaining interface editor draft and shows the
network menu. File sections and logical configuration contexts follow the same
discard/navigation behavior.

`next` continues to leave an item while keeping its edits staged. `end` saves an
active editor draft; `abort`/`cancel` discard the whole unsaved editor draft.
`back` never writes files, saves a network candidate or applies networking.
Previously saved network candidates are kept. In navigation menus, `end` returns
to the main prompt without saving.

## Install or update

Use the matching amd64 or arm64 package. Existing installations can update with:

```sh
sudo termctl update /path/to/safeterm-offline-amd64
```

Finish or roll back a pending network trial first. Reconnect existing terminal
sessions after the update. The grouped v0.28 administrator layout is unchanged.

## Validation

Tests cover login menus, retained command/field prefixes, CRLF, repeated and
unauthorized help, item/section discard boundaries, preserved drafts in other
items, nested menu navigation and completion. The deployment/SSH test continues
an authorized command directly after help. The systemd Console PTY smoke test
checks login discovery, retained input and section discard through the real
configuration writer. Existing security and race checks remain release gates.
