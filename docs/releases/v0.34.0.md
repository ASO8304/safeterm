# SafeTerm v0.34.0

Netcat TCP/UDP probes, future Ethernet interfaces and persistent MAC-based names.

## Connection tests

- `execute tcp-test IP [PORT]` now executes the approved OpenBSD netcat binary
  with fixed outbound probe flags. TCP still defaults to port 23.
- `execute udp-test IP PORT` uses netcat UDP probes. Silence is inconclusive,
  not proof of an open port; inconclusive results use exit code 2.
- Both commands retain literal-IP/single-port validation, netops authorization,
  executable hashes, bounded runtime, Ctrl+C and audit controls. No Nmap or new
  sudo grant is required. The deprecated telnet alias and permission ID remain.
- Targets require `netcat-openbsd`. The installer checks this before stopping
  services and can provision it with `--install-dependencies`, or offline.

## Future interfaces

Set `"allow_all_interfaces": true` in `/etc/safeterm/network/policy.json` to
allow current and future supported Ethernet/VM NICs within the configured roles
and source restrictions. The default is false. Interfaces without a Netplan
definition now appear with their MAC addresses. Confirming their changes creates
MAC-matched entries in `/etc/netplan/90-safeterm-interfaces.yaml`; rollback can
remove a newly created source. Restricted file policies must allow that basename.

## Persistent names

```text
execute network rename ens192 lan0
```

The change takes effect on the next reboot/device activation. SafeTerm reuses
an existing matching MAC rule such as `10-persistent-net.link`, preserving its
comments, unrelated settings and metadata. It creates a MAC-specific
`10-MAC-persistent-net.link` only when no matching file exists. Netplan matching
is converted to the MAC so the NIC retains its configuration after renaming.

No active interface is renamed, no networking is applied and no reboot is
performed. Current and future names must be allowed; candidates must be
applied/confirmed or discarded first. Ambiguous/shared rules, drop-ins and
untrusted files require administrator resolution. Persistent writes are audited,
locked, validated and journaled for recovery. The interface view shows MAC and
configured persistent name.

Coverage includes fixed netcat argv, real TCP/UDP Console probes, cancellation,
role checks, MAC display, future-NIC creation and rollback, existing-rule
preservation, simulated post-rename discovery and isolated real Netplan trials.
