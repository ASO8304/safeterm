# SafeTerm v0.37.0

Make administrator inspection agree with the restricted terminal and identify
the exact installed or packaged executable.

- Add `termctl version` and `termctl --version`. Output includes the binary's
  embedded release/module version, source commit and clean/modified state, Go
  compiler, platform and executable path. It works without root, configuration
  loading or running services, including when configuration validation fails.
- `termctl catalog` now advertises `tcp-test` instead of the internal `telnet`
  ID. Catalog description accepts both names and explains the deprecated alias
  and retained permission identity. Role inspection uses the public name too.
- Default-operation lookup and completion accept `tcp-test`, while emitted JSON
  keeps the original signed ID so existing policy grants continue to work.
- Package smoke tests compare packaged/installed binary bytes and version data,
  and verify the public catalog name after a real disposable installation.

To inspect a package before updating:

```sh
./payload/bin/safeterm-termctl version
termctl version
sudo termctl update /path/to/extracted/package
```

Extracting or downloading an archive does not replace installed binaries.
The `new_interface_file` network policy option requires v0.36.0 or newer;
v0.35.0 rejects that field. Network behavior from v0.36.0 is retained.
