# SafeTerm v0.40.0

The final execution summary is now optional. In `/etc/safeterm/terminal.json`:

```json
{
  "name": "safeterm",
  "prompt": "{brand}::{user}{context}{dirty}> ",
  "show_result": false
}
```

- `false` hides `result: success exit=0` and detailed failure-summary metadata.
  This is the production default, including when the option is omitted from an
  existing settings file.
- `true` restores the detailed result/exit-code/message footer for debugging.

Normal command output and stderr remain visible. Failed commands show a short
error, and rejected commands retain their rejection reason. Console and SSH use
the same setting for both ordinary and streaming commands. Audit logging,
authorization and actual operation exit codes are unchanged.

Run `sudo termctl check` after editing. Open a new Console session to load the
setting. For SSH, restart `safeterm-ssh-broker.service` and reconnect. Package
updates preserve your existing presentation settings.

Regression coverage includes both values, production default behavior, command
output/error visibility, streaming results, and real Console commands in the
disposable installation workflow.
