# SafeTerm v0.30.0

Make configuration editing consistent across SSH and Console, with visible drafts,
clear navigation and readable network output.

## Commands and draft state

- `save` replaces `end`: validate and commit application changes, or validate and
  commit a private network candidate. Network activation still requires
  `execute network apply` and confirmation during the timed trial.
- `cancel` replaces `abort` and discards the current editor draft.
- A `*` after the prompt context marks unsaved edits. Restoring non-secret fields
  to their initial values clears the marker.
- `back` moves up and discards edits to the item being left, reporting its name.
  `next` moves up while retaining edits. Logical contexts can also retain drafts
  in their parent menu; reopen the context to continue or save it.
- `exit`, `clear` and `whoami` work inside every editor. Dirty exit warns, discards
  drafts and closes the session; contextual help never executes a command.

Use `execute tcp-test IP [PORT]` for TCP port probing. `execute telnet` remains a
deprecated alias and prints `Use 'execute tcp-test' for port probing`. Existing
signed operation IDs, permissions and probe limits are preserved.

## Network presentation and validation

Interface summaries show NAME, STATE, DHCP4, ADDRESSES and EDITING. STATE is the
kernel operational state sampled at editor entry, or unknown if unavailable.
Editing permission is displayed separately, including policy restrictions.
Link-state changes do not invalidate candidates or become configuration edits.

Selected interfaces use labeled values, inherited DNS/search defaults, absolute
source filenames and `(staged)` indicators. Missing CIDR prefixes are rejected
immediately with an Address/Prefix example. Renderer restrictions name the actual
unsupported renderer.

Local interface, route and application diffs show removed (`-`) and added (`+`)
lines, including route creation/deletion and list ordering. Secrets stay redacted.

## Updating

Update the matching amd64 or arm64 package and reconnect. Existing administrator
configuration under `/etc/safeterm` is preserved. Update scripts do not apply
network configuration. Admin training and scripts should use `save`, `cancel` and
`tcp-test`; `end` and `abort` are no longer editor commands.

Regression coverage includes effective dirty state, item-specific discard,
retained logical drafts, globals and safe exit, cached readable views, CIDR
validation, secret redaction and authorization-preserving TCP aliases. The
release retains the full verification, security, race, SSH, systemd Console and
isolated Netplan gates.
