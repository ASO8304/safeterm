# SafeTerm v0.31.0

Add a consistent color theme to the interactive SSH and Console terminals.

- Cyan SafeTerm branding, command names, completion choices and table headings.
- Green authenticated username, successful results, up/allowed states and diff additions.
- Blue configuration context paths, distinct from the prompt identity.
- Amber unsaved `*`, staged values, warnings and down/read-only states.
- Red errors, unsuccessful results and diff removals.

The theme uses the terminal's own ANSI palette and resets before typed input.
Descriptions and ordinary values keep the default foreground. Tables are aligned
before styling; text, navigation and command semantics are unchanged.

SSH uses the terminal type supplied in its accepted PTY request. Console uses
TERM after requiring an interactive terminal. Unset TERM, TERM=dumb, and a
nonempty NO_COLOR in the broker process environment keep plain output. Embedded
shell users retain plain output unless SetTerminal is called before Run.

Only a fixed set of SafeTerm style codes may emit ANSI escapes. Resource names,
errors and operation output still pass through terminal control-byte filtering.
Passwords remain hidden; cursor movement, completion and retained question-mark
help keep their existing behavior.

Regression coverage includes plain/color output equivalence, table alignment and
semantic statuses, prompt redraw, contextual help, secret entry, terminal escape
filtering and real SSH PTY negotiation. The release retains full verification,
security, race, Console/systemd and isolated Netplan gates.

Both amd64 and arm64 offline packages are provided. Reconnect after updating to
see the theme. Administrator configuration and network apply behavior are unchanged.
