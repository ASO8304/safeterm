# Security Policy

Please report suspected vulnerabilities privately through GitHub's private
vulnerability reporting feature for this repository. Do not include secrets,
private keys, production configuration, packet captures, or exploit traffic in
a public issue.

Include the affected version or tag, deployment profile, reproduction steps,
observed impact, and any proposed mitigation. The maintainers will acknowledge
the report, reproduce it against a supported release, and add a regression test
for confirmed findings before coordinated disclosure.

Only the latest tagged milestone is supported during active development. The
project threat model and known exclusions are documented in
`docs/security/threat-model.md`.
